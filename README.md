# 🏗️ G3 Architects – Responsive Website

A modern and fully responsive architecture website built using **HTML and CSS**. This project showcases a clean UI design, smooth layout, and mobile-friendly experience across all devices.

---

## 🚀 Live Demo
🔗 https://azizulislamch.github.io/g3-architects-responsive-website/
<br> *(Live page hosted on GitHub Pages)*

---

## 📌 Features

- ✅ Fully responsive (Desktop, Tablet, Mobile)
- 🎨 Modern and clean UI design
- 📱 Mobile-friendly layout
- 🧩 Well-structured sections (Banner, Features, Team, Sponsors, Facts)
- ⚡ Smooth user experience
- 🖱️ Interactive UI elements

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox & Grid)  
- Google Fonts  

---

## 📂 Sections Included

- 🔹 Banner / Hero Section  
- 🔹 Features Section  
- 🔹 Team Section  
- 🔹 Some Facts Section  
- 🔹 Sponsors Section  
- 🔹 Footer  

---

## 🎯 Purpose of the Project

This project was created to practice:
- Responsive web design  
- Layout structuring using Flexbox & Grid  
- Building real-world landing pages
